--- ## 1. Prerequisites These must be done before you can create a CLP. The system enforces them.
1 Add Subjects

Go to My Subjects (/teacher/subjects) and add the courses you're teaching this semester. Include course code, title, units, department. The CLP create form pulls metadata from here.

2 Set Consultation Hours

Go to your Profile (/teacher/teacher_profile) and set at least one consultation day with a time and room. The system will block generation until this is done.

3 Template Profile

Optional but recommended: upload or confirm a Template Profile at /teacher/template-profiles. This ensures the generated DOCX matches your institution's exact format. Profiles are department-scoped.

--- ## 2. The Create Page — Entering Metadata Navigate to Create CLP (/teacher/copilot/create) from your dashboard. This one form is the entry point for all CLPs. ### Sections on the Create Form

1. Course Metadata

The active term is shown at the top. Pick a subject from your pre-added list. Its code, title, department, and other details are filled automatically from the subject record.

2. Teaching Logistics

Fill in Class Schedule (e.g., "Mon/Wed 1:00–2:30 PM") and Room Assignment. These go into the generated DOCX.

3. Signatory Information

Four signatory blocks that populate the document's signature page. Each has a name field and a position/title field:

Prepared By
(you — Instructor)
Reviewed By
(Program Coordinator)
Endorsed By
(Dean)
Approved By
(Vice President)

Defaults are pulled from your profile and department signatory settings. You can override them here and later on the review page.

4. Context for the AI Draft

Service Learning Component — describe any community-based learning component.
Source Context — paste any existing syllabus text, notes, or references you want the AI to use as input material.

5. Template Profile (optional)

If you have confirmed template profiles, a dropdown lets you choose one. When selected, the system runs a compatibility check:

  • ✓ Compatible — green check, proceed normally.
  • ⚠ Warning — the profile's structure partially matches your subject. You can check "I understand the mismatch — continue anyway" to proceed.

You can also Upload a new template or Manage profiles from links below the selector.

### Generating Click Generate Draft. The system: 1. Saves the initial draft with status generating. 2. Redirects you to the review page. 3. Background tasks generate the CLOs, alignments, and weekly plan asynchronously. 4. A progress overlay shows the generation status — do not close or navigate away during generation. --- ## 3. The Review Page — Generating & Editing Content After creation, you land on the review page (/teacher/copilot/review/<plan_id>). This is where all editing happens. ### Stage System The review page tracks your progress through stages. Each stage unlocks the next: | Stage | Label | What's available | |-------|-------|-----------------| | 0 — Metadata | Metadata ready | Review course info, edit signatories, set references | | 1 — CLOs | CLO draft ready | Generate/edit/regenerate Course Learning Outcomes | | 2 — Alignments | Alignment draft ready | Map CLOs → Program Outcomes → Institutional Outcomes | | 3 — Weekly | Weekly outline ready | Build 18-week topic plan with assessments | | 4 — Finalized | Finalized CLP ready | Validate & mark ready for template insertion | | 5 — Inserted | Inserted into template | Open in OnlyOffice for final DOCX edits | Each section is editable even if later stages aren't generated yet. You can jump around freely. ### Generation Mode Toggle At the top of the review page, you'll see a Generation Mode toggle: - **Template-Matched** (default) — the AI respects item counts from your template profile (e.g., number of CLOs, weeks). Use this when you have a template profile selected. - **Unconstrained** — no item limits. Use this if you don't have a template profile or need more flexibility. ### Step-by-Step on the Review Page **Step 1: Generate CLOs** - Click Generate CLOs (or Regenerate CLOs if already generated). - The AI proposes Course Learning Outcomes based on your subject and department context. - Each CLO has: code, title, description, taxonomy level (Bloom's), and delivery type. - You can edit any CLO inline, add new ones, or Regenerate individual CLO rows without affecting the rest. **Step 2: Generate Alignments** - Click Generate Alignments (or Regenerate Alignment). - The AI maps each CLO to Program Outcomes (PO), Institutional Outcomes (IO), Graduate Attributes, and Core Values. - Each alignment list is limited to 1–3 items. If the AI generates more, it's automatically clamped. - You can edit individual alignment links. **Step 3: Generate Weekly Plan** - Click Generate Weekly (or Regenerate Weekly). - The AI builds an 18-week roadmap. Each week includes: topic, linked CLOs, teaching method, assessment type, and delivery mode. - Click any week row to expand and edit individual fields. Changes save immediately. - You can regenerate individual weeks without losing the rest. ### Validation & Final Review After all three sections are generated: 1. Click Validate & Mark Ready. 2. The system runs a final AI review, checking for: - Missing content in any section - CLOs not linked to any week - Broken or missing outcome mappings - Weeks without topics or assessment methods - Inconsistent signatories 3. If issues are found, a red panel appears with details. 4. Click Fix With AI to let the AI auto-repair the flagged issues, or fix them manually. 5. If only warnings appear (amber panel), you can proceed. 6. Once passed, the stage advances to "Finalized CLP ready". ### Insert Into Template When finalized: 1. Click Insert Final Data Into Template. 2. The system fills your selected (or default) DOCX template with the CLP content. 3. On success, the stage advances to "Inserted into template". 4. You can now Open Inserted Document to edit in OnlyOffice (browser-based Word editor). #### OnlyOffice Editing Once inserted: 1. Click Open Inserted Document to launch the OnlyOffice editor in your browser. 2. Make final formatting tweaks, adjust tables, fix any DOCX layout issues. 3. The document auto-saves back to the system. 4. Any changes in OnlyOffice are preserved when you download the final file. ### Action Buttons Summary | Button | When available | What it does | |--------|---------------|-------------| | Generate CLOs | Stage 0 | AI generates Course Learning Outcomes | | Regenerate CLOs | Stage 1+ | Replace all CLOs with new AI output | | Regenerate [CLO #] | Stage 1+ | Regenerate a single CLO row | | Generate Alignments | Stage 1+ | AI maps CLOs to Program/Institutional Outcomes | | Regenerate Alignment | Stage 2+ | Replace all alignments | | Generate Weekly | Stage 2+ | AI builds 18-week topic plan | | Regenerate Weekly | Stage 3+ | Replace all weeks | | Regenerate [Week #] | Stage 3+ | Regenerate a single week row | | Validate & Mark Ready | Stage 3+ | Run final AI review | | Fix With AI | Stage 3+ (when issues found) | Auto-repair validation issues | | Insert Final Data Into Template | Stage 4 | Fill DOCX template with CLP content | | Open Inserted Document | Stage 5 | Edit in OnlyOffice | | Save Draft | Any time | Save all changes | --- ## 4. Submitting to Dean Once your CLP is complete (DOCX inserted and edited): 1. Go to My CLPs (/teacher/my_clps) from the sidebar. 2. Find your CLP card and click Submit to Dean. 3. The status changes to Pending. 4. You can no longer edit the plan while under review. ### If the Dean Returns It 1. You'll receive a notification (bell icon, top bar). 2. The status changes to Returned. 3. Open the plan — the Dean's comments appear at the top of the review page. 4. Open the document in OnlyOffice to make the requested changes. 5. Click Submit to Dean again to resubmit. ### Status Reference | Status | Badge | What it means | |--------|-------|---------------| | Draft | Draft | Still working on it | | Generating | Generating | AI is generating in the background | | Pending | Pending | Awaiting Dean's decision | | Returned | Returned | Dean requested changes | | Approved | Approved | Dean approved the plan | | Finalized | Finalized | Final version — read-only | --- ## 5. Template Profiles Template Profiles are DOCX layouts that the AI uses when generating and inserting your CLP document. ### How They Work 1. **Upload a DOCX** at /teacher/template-profiles/upload — your institution provides a template with placeholder markers ({{course_title}}, {{clo_table}}, etc.). 2. **Confirm the profile** — the system scans the template, detects its structure (tables, headings, placeholders), and shows you a summary. You confirm it looks right. 3. **Select it** when creating a CLP or on the review page. 4. **Generate** — the AI adapts its output to match the template's detected layout, column structure, and item counts. 5. **Insert** — when you click "Insert Final Data Into Template", the system fills the actual DOCX with your CLP content. ### Managing Profiles | Action | Where | |--------|-------| | View profiles | /teacher/template-profiles | | Upload new template | /teacher/template-profiles/upload | | Confirm / re-profile | Click a profile → Confirm or Re-Profile | | Clone | Click a profile → Clone | | Set department default | Admin action in department settings | | Delete | Click a profile → Delete | > Tip: If no profile is selected, the system uses a built-in default placeholder template. The output will still be structured, but may not match your institution's official format. --- ## 6. Subjects ### Adding Subjects Go to My Subjects (/teacher/subjects): 1. Click Add Subject. 2. Fill in: course code, title, description, type (lecture/lab/workshop), units, contact hours, prerequisites, department, and service learning component. 3. The subject becomes available immediately when creating a CLP. Subjects are semester-specific — the system checks the active semester and academic year. --- ## 7. Versions & History Every time you save or generate, a version snapshot is created. - Go to Versions on any CLP to see its history. - Each version records: timestamp, what changed, and the user who made the change. - You can restore any previous version — the current content is replaced. - Versions are preserved even after submission, so the Dean sees what you submitted. --- ## 8.   1. Add subjects first. The create form pulls metadata from subjects — you can't generate without them.
  2. Set consultation hours. Not just recommended — the system blocks generation until you do.
  3. Upload a template profile. Without one, the DOCX output uses a generic placeholder template. A profiled template matches your institution's exact format.
  4. Review CLOs before generating alignments. Alignments depend on CLO content — bad CLOs mean bad alignments.
  5. Run Validate & Mark Ready before inserting. The final review catches common issues automatically. Fix With AI handles most of them in one click.
  6. Use OnlyOffice for final DOCX polish. The browser editor lets you adjust tables, fonts, and layout before submitting.
  7. Write actionable CLOs. Use active Bloom's Taxonomy verbs (Analyze, Design, Evaluate) instead of vague ones (Understand, Learn).
  8. Make sure your department is correct. The wrong department means wrong outcomes, copilot data, and template profiles.
